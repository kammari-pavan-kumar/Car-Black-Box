PROJECT TITLE : CAR BLACK BOX


--------------------------------------------------------------------------------------------------------------------------------------------------------

PROJECT INFO :-

            
     The concept of Black Box is mainly heard by us in case of Aeroplanes. Also known as an event data recorder (EDR) or Accident data recorder (ADR) 
the Black Box can be installed in some automobiles to record various events. 

    This Car Black Box is an embedded system designed to monitor and record important vehicle events such as speed, gear changes, collisions, and time.
The system uses a PIC18F4580 microcontroller, an RTC(Real-Time Clock) for maintaining time, and external EEPROM for permanently storing event logs.
The recorded information can later be viewed through an LCD-based dashboard.
--------------------------------------------------------------------------------------------------------------------------------------------------------

Protocol Used – I²C

The I²C (Inter-Integrated Circuit) protocol is used for communication between the PIC18F4580 and peripherals such as the DS1307 RTC and external EEPROM.

I²C is a two-wire serial communication protocol:

SDA (Serial Data) – Carries data.
SCL (Serial Clock) – Carries the clock signal.
It supports communication between multiple devices using device addresses.
The microcontroller acts as the master, while the RTC and EEPROM act as slave devices.
Each slave has a unique address, allowing the microcontroller to communicate with the required device.
It reduces the number of GPIO pins required compared with parallel communication.

In the Car Black Box, the RTC provides the current HH:MM:SS, while the EEPROM is used to permanently store event information.



A circular buffer is used to efficiently manage the limited EEPROM space available for storing event logs.

Instead of continuously increasing the EEPROM address, the storage area is treated as a circular structure. When the buffer reaches its last location, 
the next event is stored again from the first location.

For example, if the EEPROM can store 10 logs, If all 10 locations are occupied and a new event occurs, then the oldest log is overwritten by the newest log.

Applications

The Car Black Box can be used for 
 - vehicle event monitoring
 - accident/event analysis
 - driver monitoring 
 - and maintaining a historical record of vehicle activity.

Conclusion

The Car Black Box provides a simple and reliable embedded solution for recording important vehicle events. By combining the PIC18F4580, RTC, LCD, 
keypad and external EEPROM, the system can display real-time vehicle information, maintain accurate event timestamps and store logs for later analysis.
